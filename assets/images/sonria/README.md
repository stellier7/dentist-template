# Centro de Especialidades Dentales Sonría — Images

**Upload all Sonría photos here only.** This folder lives on branch `cursor/centro-sonria-b5c1`. Do not upload Sonría assets to other client branches.

## Folder map

```
assets/images/sonria/
  logo/        ← clinic logo (PNG/SVG, transparent preferred)
  hero/        ← main full-bleed hero / banner photo
  team/        ← dentist / staff headshots
  gallery/     ← smile gallery, clinic, before/after
  insurance/   ← insurance or financing logos (optional)
```

## Suggested file names

| What | Put it in | Suggested name |
| --- | --- | --- |
| Logo | `logo/` | `logo.png` |
| Hero | `hero/` | `hero.jpg` |
| Dentist photos | `team/` | `dentist-[lastname].jpg` |
| Gallery | `gallery/` | `smile-01.jpg`, `smile-02.jpg`, … |
| Insurance / financing | `insurance/` | `[provider].png` or `.svg` |

## Tips

- Hero: wide (≈16:9), ideally 1920px+ wide
- Team: square or portrait headshots, clear face, clean background
- Logo: transparent PNG or SVG when possible
- Gallery: optional for v1; add anytime later

After you upload, tell the agent on this branch — paths will be wired into `js/config.js`.
